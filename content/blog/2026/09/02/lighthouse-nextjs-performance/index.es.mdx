## El resultado

La performance no vino de un truco aislado. Vino de mantener el critical path pequeño: Server Components por defecto, imágenes con dimensiones conocidas y efectos visuales fuera del primer paint.

<Callout title="Regla de oro" variant="success">
  Mide el critical path antes de optimizar detalles. El usuario siente bytes y espera, no la elegancia del código.
</Callout>

## Lo que cambió

1. Las listas editoriales cargan solo metadata en el servidor.
2. El contenido MDX compila solo en la página del artículo.
3. Videos y embeds usan carga bajo demanda.

### El contrato editorial

| Campo | Papel |
| --- | --- |
| `title` | Título de la página y del card |
| `description` | Resumen, SEO, RSS y archive |
| `date` | Ordenación cronológica |
| `tags` | Taxonomía controlada |
