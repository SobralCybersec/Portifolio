## O resultado

Performance não veio de um truque isolado. Veio de manter o caminho crítico pequeno: Server Components por padrão, imagens com dimensões conhecidas e efeitos visuais fora do primeiro paint.

<Callout title="Regra de ouro" variant="success">
  Meça o caminho crítico antes de otimizar detalhes. O usuário sente bytes e espera, não a elegância do código.
</Callout>

## O que mudou

1. Listas editoriais carregam apenas metadata no servidor.
2. Conteúdo MDX compila somente na página do artigo.
3. Vídeo e embeds usam carregamento sob demanda.

### O contrato editorial

| Campo | Papel |
| --- | --- |
| `title` | Título da página e do card |
| `description` | Resumo, SEO, RSS e archive |
| `date` | Ordenação cronológica |
| `tags` | Taxonomia controlada |

```ts
const firstPaint = 'server';
const clientJavaScript = 'only when interaction exists';
```
